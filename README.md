# MyProject
# Интернет-магазин 3D-печати

Дипломный проект — интернет-магазин по продаже изделий, напечатанных на 3D-принтере (органайзеры, картхолдеры и другие аксессуары).

Проект разрабатывается с использованием современных веб-технологий и облачных сервисов.  
К концу курса в репозитории будет полноценный интернет-магазин с каталогом товаров, корзиной, оформлением заказов, личным кабинетом и интеграцией с облачным хранилищем и базой данных.
